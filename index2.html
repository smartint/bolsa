🌍 Fuente de cotizaciones

Todos los alumnos comparten los mismos precios, pero cada uno tiene su propia cartera. Para evitar ganancias o pérdidas artificiales, no se permite cambiar de modalidad mientras algún participante posea acciones: primero deben venderlas.

Necesitas Internet y una clave proporcionada por el servicio. Las cotizaciones pueden estar retrasadas, limitadas o no disponibles. Los símbolos sin datos quedan bloqueados para operar.

Ejemplo: AAPL,2026-10-30,270.25. Fecha ISO AAAA-MM-DD. Importa cotizaciones que hayas obtenido legalmente y comprueba su procedencia.

💾 Guardar y compartir la aplicación

Los cambios se guardan automáticamente en el navegador de este dispositivo. Para llevar las 24 carteras a otro ordenador, exporta una copia.

El HTML exportado incluye las carteras y puede seguir utilizándose sin conexión en modo de simulación. No sincroniza cambios entre varios dispositivos. La consulta a Finnhub sí requiere conexión. No hay cuentas, contraseñas ni control de acceso real: conserva el archivo solo en dispositivos bajo supervisión docente.

📥 Importar archivos individuales del alumnado

Admite JSON como 01ct.json (tareas EVAGD) y copias JSON completas de la Bolsa Escolar individual (créditos, saldo, acciones y operaciones). Selecciona varios archivos o una carpeta completa.

Al importar el mismo JSON EVAGD dos veces, no se vuelven a abonar las mismas tareas. En un JSON de créditos sin cartera, el «saldoDisponible» es informativo: no sustituye el saldo de la clase ni permite reconstruir acciones. Las exportaciones completas del alumno (versión 3) recuperan saldo, acciones, operaciones y tareas y sustituyen la ficha individual, previa confirmación. El precio de cada acción se calcula con el mercado común del profesor.

🧩 Gestión de la clase

Al reiniciar se recupera la lista de los 24 identificadores predeterminados, se asigna la nueva cantidad inicial y se conservan las cotizaciones y la modalidad actuales. Exporta antes una copia si deseas conservar el trabajo.

📚 Conceptos para aprender

Acción: pequeña parte de una empresa. Cotización: precio de mercado. Cartera: acciones compradas. Patrimonio: créditos disponibles más valor actual de las acciones. Beneficio o pérdida: diferencia respecto a lo invertido. Diversificación: repartir riesgos.

Las rentabilidades pasadas no garantizan resultados futuros. Las operaciones no incluyen impuestos, tipos de cambio ni costes. Una unidad de precio se representa como un crédito educativo, sin convertir divisas.
